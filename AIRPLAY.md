# Resona AirPlay fork

This fork targets AirPlay album artwork and a dedicated TV Now Playing display on iOS.

Base: savo-o/resona v2.0 (0adbfd1).

## Output modes

- Audio only: stream audio, artwork and track metadata using the standard AirPlay audio route. The receiver controls the TV screen.
- TV display: use Screen Mirroring for an independent artwork window while Resona remains the controller on the iPhone. Keep Resona open and the iPhone unlocked.

## Layouts

Cinema, Gallery, Ambient and Night, using a square cover with a faded full-screen background.

## Verification

Implementation and tests are in preparation. No successful iOS build or physical LG TV test has been recorded yet.
